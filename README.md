# Freight rate prediction

Predict freight `posted_rate` from labeled January-October 2025 loads and generate predictions for every November-December load. The model uses robust, regularized regression on log rate. A boosted-tree model did not consistently improve on it across forward validation windows.

## Results and validation

The main development file, `data/train-test.csv`, has 48,000 labeled loads. The final input, `data/validation.csv`, has 12,000 unlabeled loads. Source filenames use hyphens in this checkout. The training script also accepts the underscore names from the original instructions.

- Model selection: train January-April, validate May-June; train January-June, validate July-August.
- Final performance check: train January-August, evaluate 9,523 September-October loads.
- Final refit: use all January-October labels and predict every November-December input.

These splits match the two-month forecast horizon and avoid training on future dates. Each training window determines the imputation values, coordinate lookups, standardization, spline knots and encoders. Exploratory data analysis examined the full development file. Model selection did not use scores from the final performance period, but that period is not a blind external benchmark.

On the final check, MAE is $146.78, WAPE is 6.13%, RMSE is $644.53 and R-squared is 0.822. The equipment median-RPM baseline has $229.10 MAE, so the model reduces MAE by 35.9%. Large errors remain, particularly for expensive loads, and mean signed error is -$122.70. Calculating November-December accuracy requires labels that are not available locally.

See `output/pdf/freight_rate_report.pdf` for the complete split rationale, data audit, features, comparisons, limitations and December chart. The Markdown version is in `reports/freight_rate_report.md`.

## Setup

Use Python 3.12. This assessment used a separate `.venv-ml` environment.

```bash
python3.12 -m venv .venv-ml
source .venv-ml/bin/activate
python -m pip install -r requirements-lock.txt
```

`requirements-lock.txt` records the exact tested package versions. `requirements.txt` lists direct dependencies with compatible bounds.

## Reproduce predictions and checks

Run from the repository root after activating the environment:

```bash
python train.py
python diagnostics.py
python score.py --predictions validation_predictions.csv --december-predictions data/december-chart-inputs.csv
python make_report.py
python -m unittest discover -s tests -v
```

`make_report.py` generates only `artifacts/holdout_diagnostics.png`. The image contains an actual-versus-predicted scatter plot and an absolute-error histogram. The script does not generate or overwrite the PDF or Markdown reports.

If cache permissions prevent plotting, set `MPLCONFIGDIR=/tmp/freight-mpl` before running the plotting scripts.

To regenerate predictions from the saved model without fitting:

```bash
python train.py --predict-only
```

The pipeline checks ID uniqueness, exact ID coverage between validation data and the template, temporal separation, valid dates, positive distances and positive training targets. It joins predictions to the template by ID and preserves the template's order. It fits preprocessing and models using labeled training data only. Runs use fixed seeds and round predictions to two decimal places.

## Modeling details and caveats

The pipeline treats non-positive weights as missing. It learns numeric medians and indicators from training data only and keeps rows with expensive loads. The regression predicts log rate using a small distance spline, city, equipment and weekday indicators, coordinates, weight, market index, quote signal and one annual sine/cosine pair. Ridge alpha is 10. Robust fitting uses 12 residual-reweighting iterations. Model selection uses mean dollar MAE across forward validation windows, with a fixed 2% preference for the simpler candidate in the declared order.

The relationship between `quote_signal` and the target changes across months. Testing with and without it favored including it in both selection windows. Before production use, verify its source and availability at quote time. Eight cities are new in the final inputs. The report includes a separate early-period hidden-city stress test.

December's fixed-input file has no market index, quote signal or coordinates. Its companion model trains without the two signals and recovers known-city coordinates from the training data. It achieves $165.83 MAE on September-October data with the same reduced input schema. Learned weekday and smooth annual effects determine the December predictions. The model has no learned Christmas-specific effect, and no December labels are available to validate the curve.

```bash
python inspect_data.py
```

`artifacts/eda/`, including `summary.txt`, `audit.json`, `schema.csv`,
